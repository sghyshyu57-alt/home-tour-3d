# 房屋漫游 3D 模型

直接打开：**https://sghyshyu57-alt.github.io/home-tour-3d/**

手机或电脑浏览器均可查看。俯视模式支持拖动旋转、缩放；漫游模式可走入室内，手机用屏幕方向键移动并拖动画面转向。

点击网页里的“批注”，可截取当前模型视角或导入照片，画箭头、圈选和文字，导出 PNG 后用于反馈房间布局。导入的照片只在当前浏览器处理，不会上传到网站。

模型根据视频和照片估算，仅用于空间与家具位置的多角度查看，不作为施工尺寸依据。仓库的 `docs/` 是 GitHub Pages 发布目录。

当前版本：Blender v6（2026-09-30）。对照参考照片和视频改进了暖棕木纹、柔软抱枕及颜色顺序、双层山水浮雕和洗墙光照，补充下沉水槽与弯管龙头、刺绣茶垫、纸巾盒及视频中的电视画面。桌面高画质漫游带有模糊地面反射；手机版使用较轻的模型。

已检查桌面与手机尺寸下的加载、连续漫游、家具碰撞、触控、画质切换和批注 PNG 导出；手机检查为浏览器模拟视口。未经测量的房屋尺寸与缺少参考的室内饰面仍为近似值。
